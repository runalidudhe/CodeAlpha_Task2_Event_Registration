# Event Registration System

## About
A web-based Event Registration System developed using Django.

## Technologies Used
- Python
- Django
- Django REST Framework
- HTML
- CSS
- SQLite

## Features
- User Registration
- User Login
- Event Management
- Event Registration

## Installation

1. Create a virtual environment.
2. Install dependencies:

   pip install -r requirements.txt

3. Run migrations:

   python manage.py migrate

4. Start the server:

   python manage.py runserver
